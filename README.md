## Why Chinese Open Source?

China's open-source ecosystem serves **1.4 billion users** and produces software at a scale few other communities match. These projects are battle-tested:

- **Alibaba** open-sourced the tools behind Double 11 — the world's largest shopping event ($84B+ in a single day)
- **Baidu**, **Tencent**, and **ByteDance** release AI models trained on massive Chinese-language corpora
- **DeepSeek**, **Zhipu AI**, and **01.AI** push the frontier of open-weight LLMs
- **PingCAP** and **Zilliz** build globally-adopted database technology (TiDB, Milvus)
- The **WeChat ecosystem** (1.3B+ users) created development paradigms that don't exist elsewhere

Yet many of these projects remain invisible to international developers because their documentation is in Chinese. **This list bridges that gap.**

> Projects marked with `EN` have English READMEs. All others default to Chinese — but every entry below includes an English description.
