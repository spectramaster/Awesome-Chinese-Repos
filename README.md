# Awesome Chinese Repos [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of outstanding open-source projects from China's developer community, translated and organized for the international audience.

China has one of the world's most vibrant open-source ecosystems, yet many exceptional projects remain undiscovered by international developers simply because their documentation is in Chinese. This list bridges that gap — every project here was built by Chinese developers or teams, and each entry includes an English description to help you evaluate and adopt these tools.

Projects marked with `[EN]` have English READMEs. All others default to Chinese documentation.

**Why this list?** China produces mass-scale enterprise systems, cutting-edge AI models, battle-tested Java frameworks, and unique mobile ecosystems (WeChat Mini Programs) that you won't find elsewhere. Dive in.
