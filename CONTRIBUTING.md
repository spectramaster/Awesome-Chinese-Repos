# Contributing to Awesome Chinese Repos

Thank you for your interest in contributing! This list aims to be the best curated collection of Chinese open-source projects for the international developer community.

## Criteria for Inclusion

A project must meet **all** of the following:

1. **Chinese origin** — Built by Chinese developers, teams, or companies
2. **Open source** — Hosted on GitHub with a recognized open-source license
3. **Quality** — Well-maintained, reasonably documented, and actively used
4. **International value** — Solves problems or provides tools that international developers would find genuinely useful
5. **Non-political** — No politically sensitive content

## How to Submit

1. Fork this repository
2. Add your project to the appropriate category in `README.md`
3. Follow the format: `- [owner/repo](link) - English description. ![Stars badge]`
4. Submit a Pull Request with:
   - Why this project would interest international developers
   - Which category it belongs to
   - Whether the README is in Chinese or English `[EN]`

## Format Guidelines

- **Description**: Write a clear, concise English description (1-2 sentences)
- **Category**: Place the project in the most relevant existing category
- **Star badge**: Include `![Stars](https://img.shields.io/github/stars/owner/repo?style=flat-square)`
- **EN tag**: Add `[EN]` after the link if the repo's README is primarily in English
- **Alphabetical**: Within each category, entries are sorted by star count (descending)

## What NOT to Submit

- Projects with fewer than 500 stars (unless exceptionally unique)
- Abandoned/archived projects with no activity in 2+ years
- Personal forks or mirrors
- Projects that are primarily English-community driven
- Political, religious, or controversial content
- Duplicate entries

## Updating Descriptions

If you find a description that could be improved or is inaccurate, PRs for description updates are welcome! Accuracy matters.

## Questions?

Open an issue if you're unsure whether a project fits. We'd rather discuss than decline.
